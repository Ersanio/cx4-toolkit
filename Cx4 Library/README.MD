# Library

These are Cx4 routines and the calls that make them, that might be practical to use in your own projects. A bit impractical to easily demo, but it would be a waste to not include these proofs-of-concepts.

## Usage

See Super Mario World for examples of how to call these routines. Use the Macros to embed these program pages into your ROM, then call the pages using the Cx4 hardware registers.
